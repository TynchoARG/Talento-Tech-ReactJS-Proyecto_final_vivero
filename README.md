# Vivero Siempre Verde 🌵🌸
### Proyecto Final - Curso de ReactJS | Talento Tech

¡Bienvenido a **Vivero Siempre Verde**! Este proyecto es una aplicación web de comercio electrónico (E-commerce) completamente funcional, desarrollada en ReactJS.
 La plataforma permite a los usuarios explorar un catálogo elástico de plantas, macetas e insumos de jardinería, gestionar un carrito de compras en tiempo real y ofrece un panel de administración exclusivo para la gestión de productos y cupones de descuento.

---

## 🚀 Características Principales

*   **Catálogo de Productos:** Grilla interactiva y elástica adaptada para la venta de plantas, macetas e insumos.
*   **Detalle del Producto:** Vista individual optimizada para conocer en profundidad las especificaciones y precios de cada artículo.
*   **Carrito de Compras Modular:** Sistema de gestión centralizado (Context API) para agregar, remover cantidades y calcular subtotales y totales automáticamente.
*   **Autenticación Segura (Firebase Auth):** Sistema integrado de inicio de sesión (*Login*) y registro de nuevos usuarios (*Sign Up*), incluyendo alertas inteligentes para correos duplicados.
*   **Panel de Administración (Control de Roles):** Filtro de seguridad que permite únicamente a los usuarios con rol de administrador gestionar la persistencia de datos:
    *   **Gestión de Productos:** Alta, edición y baja de stock/artículos conectados con persistencia de imágenes externas (ImgBB API).
    *   **Gestión de Cupones:** Creación y edición dinámica de códigos promocionales de descuento para la tienda.
*   **Diseño 100% Responsive:** Interfaz moderna y consistente adaptada minuciosamente para celulares, tablets y computadoras de escritorio utilizando CSS Modules y Flexbox.

---

## 🛠️ Tecnologías Utilizadas

*   **Frontend:** ReactJS, JavaScript (ES6+), HTML5, CSS Modules (Flexbox & Grid).
*   **Enrutamiento:** React Router Dom.
*   **Base de Datos y Autenticación:** Firebase (Firestore Database & Firebase Authentication).
*   **Imágenes:** Integración con API de ImgBB para el almacenamiento de archivos multimedia del catálogo.
*   **Herramienta de Construcción:** Vite.
